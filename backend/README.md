# Ben and Maya call backend

Standalone prepared-call service for the Cedar Home tour. Runs HTTP and WebSocket endpoints only; no studio, TTS generator or private app routes are included.

Render sets PORT and RENDER_EXTERNAL_URL. Set TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, TWILIO_FROM_NUMBER, PUBLIC_DEMO_PIN and PUBLIC_DEMO_ORIGIN as private environment variables. PUBLIC_DEMO_CALL_LIMITS=0 disables daily/per-mobile allowances for this free hosted demo. The code is never embedded here.

One call can run at a time. Calls end after four minutes. PIN attempts, session ownership, approved clip IDs and signed Twilio hooks are validated. Incoming phone audio is discarded. Health check: /healthz. Free hosting may need a cold start; manual deploys avoid interrupting a demonstration.

Source and export tooling remain in the authoring repository. This directory is generated by npm run twilio:backend:export.
